### Text Adventure Game: The Case of the Vanishing Footnote ✅

A humorous text-based mystery game set inside a strange library. The player investigates the disappearance of a missing page from a rare manuscript by questioning suspects, collecting clues, and making choices that lead to different endings.

#### What it does

- Asks the player for their detective name
- Presents a library mystery story
- Lets the player make choices throughout the investigation
- Tracks clues and items using variables
- Uses conditional logic to change the story based on player choices
- Includes multiple endings depending on the player's decisions

#### Game features

- Mystery story set in a library
- Humorous suspects:
  - Professor Crumbly
  - A nervous photocopier
  - A suspiciously literate cat
- Clues and items:
  - Catalog card
  - Muffin
  - Photocopier receipt
  - Photocopier evidence
- Multiple endings:
  - Winning ending
  - Losing endings
  - Neutral/funny endings

#### Skills practiced

- User input
- `if`, `elif`, and `else` statements
- Boolean variables
- Choice validation
- Branching story paths
- Basic game logic
- Ending the program based on outcomes

#### What I learned

This project helped me understand how conditionals can control the flow of a program. I also practiced using variables to remember earlier player choices and change later outcomes in the game.

#### Future improvements

- Add a replay option
- Add more rooms to explore
- Add a score system
- Add more clues and suspects
- Use functions to organize the code better
